### Project Title
Explore US Bikeshare Data

### Description
A Python program that analyzes US bikeshare data for Chicago, New York City, and Washington.
 It lets the user filter by city, month, and day, then shows statistics on popular travel times, stations, trip duration, and users.

### Files used
bikeshare.py, new_york_city.csv, chicago.csv, washington.csv
